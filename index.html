Data ditampilkan langsung dari endpoint crud-products. Perubahan disimpan ke database melalui Edge Function. Gunakan Edit JSON untuk mengatur seluruh field product dan variants sesuai schema API.

Add product

POST · title dan item_group_id wajib. variants harus berupa array; setiap variant wajib memiliki id.
Field product: title, description, brand, gtin, mpn, item_group_id, availability, condition, quantity_to_sell_on_facebook, expiration_date, link, google_product_category, product_type, rich_text_description, custom_label_0, sale_price_effective_date, variants. Variant: id, size, color, price, image_link, sale_price, additional_image_link.

API Settings

Key publishable/anon boleh digunakan di browser. Jangan masukkan service_role atau secret key. Pengaturan disimpan di localStorage browser ini.
